# Cuaderno del análisis

`SPAQ_FASE3_COMPACTO_EJECUTADO.ipynb` contiene el análisis completo que produjo los datos y los modelos de la aplicación: cálculo de características, regresión, clasificación de escenas, agrupación y redes neuronales.

Está ejecutado, es decir, incluye las salidas de cada celda.

## Antes de reejecutarlo

- En la primera celda, la variable `ROOT` apunta a `RUTA_DEL_PROYECTO`. Cámbiela por la carpeta donde están las fotos y las anotaciones de SPAQ.
- Las fotos de SPAQ no se incluyen en este repositorio. Se obtienen de la fuente original (ver el README principal).
